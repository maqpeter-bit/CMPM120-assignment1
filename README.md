# CMPM 120 - Assignment 1 Framework

I have added in first and foremost the item requirements, which first check if it needs any requirements to begin with, then iterates through the player's inventory to ensure they have all the requirements. 

Additionally, the first interaction I made is one that can be either a dog or a cat, and a bone. Giving them a bone changes the text depending on whether it was a dog or a cat. 

The second interaction I made is one that requires "The generic room man" AND a bone. Once both are met, an action happens. 

The third interaction requires just a single item in the inventory. This is just a basic check. 

The player can also get extra points depending on if they have the special lightbulb when they reach the exit. 

The game's check do work with the randomized map generator as well.
